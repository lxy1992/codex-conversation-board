# Security Policy

## Scope

The board reads local application metadata and writes local status files. Reports involving path
traversal, command execution, cross-origin web access, unintended transcript reads, or disclosure of
local conversation metadata are especially important.

## Reporting

Use GitHub's private vulnerability reporting for the repository after publication. Do not include
real conversation content, credentials, account identifiers, or full home-directory paths in a
public issue. A maintainer will confirm receipt and coordinate a fix before public disclosure.

## Supported version

Security fixes target the latest released version.
